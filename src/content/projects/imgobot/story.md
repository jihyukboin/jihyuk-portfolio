# 친구의 고민에서 발견한 문제

임고봇은 초등교사가 되길 희망하는 교육대학교 학생들의 학습 고민을 해결하기 위해 시작된 프로젝트입니다. 초등 임용시험 1차 필기는 전 과목 교육과정 원문을 바탕으로 출제되어 암기해야 할 분량이 방대합니다. 2024년, 컴퓨터공학과로 편입학하여 전공 수업에 적응하던 무렵, 임용시험 준비로 극심한 스트레스를 받던 친구의 고민을 듣게 되었습니다.

문제의 핵심은 기존 암기 학습 플랫폼들이 가진 두 가지 한계점에 있었습니다. 첫째, 정적인 페이지 구조로 인해 새로고침을 하거나 재접속할 경우 이전 학습 진행 상황이 초기화되었습니다. 둘째, 학습 성취도와 무관하게 항상 동일한 위치에 뚫린 빈칸 문제만 반복 제공되어, 교육과정 내용 자체가 아닌 빈칸의 위치를 외우게 되는 부작용이 있었습니다. 이를 개선해 기존 도구들의 단점을 보완하고 장점만을 결합한 웹서비스를 직접 만들기로 결심했습니다.

# 임고봇의 탄생과 첫 번째 서비스: 교육과정 아웃풋

임고봇은 '임용고시를 돕는 AI 봇'의 줄임말입니다. 사용자 맞춤형 콘텐츠를 제공하기 위해 과거 경험이 있던 OpenAI의 GPT-3.5 API를 활용, 난이도별로 콘텐츠를 분류하고 생성하는 기능을 기획했습니다.

가장 먼저 직면한 과제는 NCIC(국가교육과정정보센터)에서 제공하는 1,000페이지 이상의 과목별 교육과정 원문을 서비스에 적합한 데이터 형태로 변환하는 일이었습니다. 이를 위해 텍스트를 입력하면 '원문'과 '키워드'로 분리된 JSON 형태로 반환하는 자동화 워커를 구축했습니다. 약 4만 원의 API 비용과 3일의 추출 시간, 그리고 2일의 검수 과정을 거쳐 마침내 교육과정 원문 데이터셋을 완성할 수 있었습니다.

첫 배포는 비교적 진입 장벽이 낮은 Streamlit을 활용했습니다. 퀴즈 기능 1개를 탑재한 다소 어설픈 형태였지만, 일주일 만에 5명의 사용자가 모였습니다. 전 범위 교육과정 학습이 가능하다는 긍정적인 피드백을 받으며, 아이디어를 실천으로 옮기는 도구로서 AI가 지닌 잠재력을 체감했습니다. 동시에 서비스를 고도화하기 위해서는 더욱 안정적인 맞춤형 환경이 필수적이라는 것을 깨달았습니다.

# 본격적인 웹 서비스로의 전환: 28번의 시도와 AWS 도입

더 나은 서비스를 위해 비교적 학습 곡선이 완만하고 웹 서버의 표준적인 프레임워크인 Node.js 기반의 Express를 채택하여 풀스택 서버를 구축했습니다. 배포는 소스 코드를 압축해 업로드하면 자동으로 인스턴스에 배포되는 AWS Elastic Beanstalk를 활용했습니다.

당시 클라우드에 대한 사전 지식이 전혀 없었기에, 오후 2시에 시작된 배포 작업은 무려 28번의 실패를 거친 후 밤 11시가 되어서야 성공적으로 마무리되었습니다. 웹 브라우저 주소창에 도메인을 입력하고 정상적으로 렌더링된 웹페이지를 마주했을 때의 기쁨은 이루 말할 수 없었습니다.

# 인증 시스템 설계: AWS Cognito를 선택한 이유

사용자가 늘어나면서 로그인 기능 도입이 필요해졌습니다. 자체 구현과 AWS Cognito 사용을 두고 깊이 고민했습니다. 직접 구현할 경우 유연한 정책 설계가 가능하지만, 단일 인스턴스 배포 환경에서 발생할 수 있는 정합성 문제와 보안 취약점이 우려되었습니다. 반면 AWS Cognito를 사용하면 서비스 정책 제약이 따르지만, 보안과 인증 관리를 AWS에 안전하게 위임할 수 있었습니다.

보안 관련 전공 지식이 부족했다는 점, 사용자 1,000명까지는 무료로 이용할 수 있다는 점, 그리고 로그인 자체가 임고봇의 핵심 비즈니스 로직이 아니라는 점을 종합적으로 판단하여 최종적으로 AWS Cognito를 도입했습니다.

# 유저의 피드백으로 완성한 두 번째 도약: AI 면접관

2024년 11월, 1차 필기시험 종료 후 다음 해를 대비해 서비스를 재정비하던 중 유저로부터 "2차 면접을 연습할 수 있는 기능을 만들어달라"는 피드백을 받았습니다. 유저와의 깊이 있는 대화를 통해 기존 면접 준비 방식의 한계를 파악했습니다. 스터디원들이 모여야만 연습과 피드백이 가능해 혼자서는 준비하기 어렵고, 매번 유사한 질문이 반복되며 구체적인 피드백을 얻기 힘들다는 점이었습니다.

이를 해결하기 위해 각 교육청별 기조와 중점 사항을 바탕으로 지원자의 답변을 평가하는 'AI 면접관' 서비스를 기획했고, 개발 착수 단 4일 만에 런칭에 성공했습니다. 사용자의 발화는 네이버 클로바(Clova)의 STT(Speech To Text) 모델을 통해 텍스트로 변환되었고, 이는 각 교육청의 평가 기준이 프롬프트로 입력된 OpenAI GPT 모델로 전달되었습니다. 그 결과 사용자에게 발화 전사 텍스트, 상세한 피드백, 피드백이 반영된 권장 답변 세 가지를 체계적으로 제공할 수 있었습니다.

유저의 목소리에 귀 기울여 발 빠르게 기능을 확장한 결과, 2025년을 맞이하며 임고봇은 300명의 예비 교사가 애용하는 실질적인 AI 학습 플랫폼으로 괄목할 만한 성장을 이루어냈습니다.
